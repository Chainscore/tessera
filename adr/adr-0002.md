## Iteration 1 State Update Flow (Current)

```mermaid
flowchart TD
    A([Start Update State]) --> B[(Load whole tree from DB)]
    B --> C[Begin recursive update update_tree]
    
    subgraph RECURSIVE_UPDATE [Recursive Node Update]
      C --> D{Current Node Type?}
      
      D -- "Empty" --> E[Create new leaf node - Encode leaf with key & value]
      E --> F[Compute hash for new leaf node]
      F --> G[Return leaf node hash & structure]
      
      D -- "Leaf" --> H{Does key match?}
      H -- Yes --> I[Update leaf node - Encode new leaf with new value]
      I --> J[Compute hash for updated leaf]
      J --> G
      H -- No --> K[Conflict on leaf: Split branch into two leaf nodes]
      K --> L[Call merkelize_recursive on both key-value pairs]
      L --> M[Compute new branch hash for split branch]
      M --> G
      
      D -- "Branch" --> N{Determine bit at current bit_index}
      N -- "Bit = 0" --> O[Traverse left child]
      N -- "Bit = 1" --> P[Traverse right child]
      
      O --> Q[Recursively update left subtree]
      Q --> R[Receive updated left child hash & structure]
      
      P --> S[Recursively update right subtree]
      S --> T[Receive updated right child hash & structure]
      
      R & T --> U[Encode branch node with new left & right hashes]
      U --> V[Compute new branch node hash]
      V --> G
    end

    G --> W{Is current node the root?}
    W -- No --> X[Return new node hash to parent's update call]
    W -- Yes --> Y[Update the global state_root key in DB]
    Y --> Z([Update Complete])
```
### Pros
- Simple to implement
- Easy to understand

### Cons
- Not scalable
- Not maintainable
- Tree of that size is not practical for millions of accounts
