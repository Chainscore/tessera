# Work package and Items

This phase of jam is responsible for processing all the in-core computations on the work package and work package's items. The whole process is stateless. It involves several interrelated sub-processes that together ensure that the work package generated by the builder computation are correctly. The key sub-processes are:

- **Generate Work Package**
- **Validator Assignment**
- **Work Package Computation**
- **Work Package Distribution**
- **Erasure coding**
