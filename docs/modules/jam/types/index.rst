Types
=========

Core type system for base types in Python and protocol types in the JAM protocol.

Module Organization
-----------------

1. Base Types (:mod:`.base`):
   * Fundamental data types
   * Direct codec implementations
   * Generic type building blocks

2. Protocol Types:
   * :mod:`.protocol`: Core protocol helper types
   * :mod:`.extrinsics`: Extrinsics types
   * :mod:`.work`: Work item and other types
   * :mod:`.header`: Header Structure
   * :mod:`.block`: Block Structure
